# FF Hub

브랜드의 이야기를 웹 화면 위의 장면으로 옮기는 스튜디오의 포트폴리오 사이트입니다.
Next.js(App Router) 로 만들었고, 화면은 서버에서 완성해 보내고 실제로 움직이는 부분만
브라우저에서 살아나도록 구성했습니다.

## 디자인 컨셉

**글래시 다크 네이비** — 짙은 네이비 어둠 위에 반투명한 유리 면을 겹쳐 쌓은 화면입니다.

- **바탕** : `#070a12` 의 깊은 네이비. 위쪽에 푸른 광원이 번지고 옅은 격자가 깔리며,
  네 갈래 별 오브제가 천천히 떠다닙니다.
- **표면** : 카드와 패널은 흰빛을 4~14% 섞은 반투명 면에 흐림(blur)을 더한 유리 질감입니다.
  테두리는 흰색 12% 선 한 겹으로만 잡아 어둠 속에서 면의 경계를 드러냅니다.
- **글자** : 제목은 Manrope 의 굵은 자간 좁힘, 본문 한글은 Pretendard.
  큰 제목에는 흰색에서 회청색으로 떨어지는 그라디언트를 얹었습니다.
- **작품 썸네일** : 각 사이트의 메인 화면을 그대로 담습니다.
  화면 전체가 어두운 만큼, 이 썸네일이 유일한 색의 출처가 됩니다.
  이미지가 없는 작품은 그라디언트 면으로 대신합니다.

움직임은 네 가지입니다.

1. **카드 기울임** — 작품 카드 위에서 마우스를 움직이면 커서를 따라 카드가 기웁니다.
2. **3D 링 캐러셀** — 작품이 그리드 노출 개수(기본 9개)를 넘으면 "더보기" 버튼이 나타납니다.
   누르면 그리드의 카드가 그 자리에서 떠올라 원형으로 날아가
   둘러싸는 형태가 됩니다. 휠·드래그·좌우 키로 돌릴 수 있고, 5초마다 한 칸씩 스스로 넘어갑니다.
   마우스를 카드에 올리면 멈추고, 바깥을 누르면 카드가 원래 자리로 되돌아갑니다.
3. **상세 모달** — 카드를 누르면 떠오르고 닫으면 가라앉습니다. 좌우 키로 작품을 순환하며,
   다음 작품으로 넘어갈 때는 이미지와 글이 한 번 사라졌다 나타나 두 화면이 겹쳐 보이지 않습니다.
4. **서비스 아코디언** — 줄을 누르면 설명이 펼쳐지고 `+` 기호가 45도 돌아갑니다.

화면 폭에 따라 세 구간으로 나뉩니다.

| 구간 | 폭 | 배치 |
| --- | --- | --- |
| 모바일 | ~ 639px | 한 칸으로 쌓고, 메뉴는 로고 아래 한 줄을 차지합니다. 보조 문구는 감춥니다 |
| 태블릿 | 640 ~ 1023px | 기준 배치를 유지하며 여백만 좁아집니다 |
| 데스크톱 | 1024px ~ | 기준 배치 |

좌우 여백은 `clamp(20px, 3vw, 40px)` 로 화면 폭을 따라 흐르고, 링 캐러셀은 모바일에서
반지름을 줄이는 대신 카드를 키워 좁은 화면에서도 내용이 읽히게 합니다.
움직임 최소화를 켠 사용자에게는 반복 애니메이션이 재생되지 않습니다.

## 실행 방법

```bash
npm install

npm run dev        # 개발 서버 — http://localhost:3000
npm run build      # 프로덕션 빌드
npm start          # 빌드 결과 실행
npm run typecheck  # 타입 검사
npm run thumbnails # 썸네일 자동 최적화 (thumbnails/source → public/works)
```

톤을 바꾸고 싶으면 그 파일만 보면 됩니다.

## 사용 방법

### 작품 추가 · 제거

`lib/data/works.ts` 의 목록 **하나만** 고치면 됩니다.

```ts
const WORK_INPUTS: WorkInput[] = [
  {
    id: 'maison-mocha',
    name: '메종모카',
    category: '카페 브랜드 사이트',
    year: '2026',
    image: '/works/maison-mocha.webp',
  },

  // 추가 — 썸네일 파일을 public/works/ 에 두고 경로만 적는다
  {
    id: 'new-site',
    name: '새 사이트',
    category: '랜딩 페이지',
    year: '2026',
    image: '/works/new-site.webp',
    // 실제 주소를 적으면 상세 화면의 "사이트 방문" 버튼이 켜진다
    href: 'https://example.com',
  },

  // 썸네일이 아직 없을 때 — 이미지 대신 그라디언트 면이 보인다
  {
    id: 'no-image',
    name: '준비 중',
    category: '브랜드 웹사이트',
    year: '2026',
    gradient: 'linear-gradient(135deg,#101820,#2f7fb0 50%,#cfeaff)',
  },

  // 제거 — 해당 블록을 지우거나 앞에 // 를 붙인다
];
```

목록을 고치면 아래가 전부 자동으로 따라옵니다.

| 반영되는 곳 | 설명 |
| --- | --- |
| 작품 그리드 | 목록 순서대로 노출. 노출 개수는 `site.ts` 의 `worksGridLimit`(기본 9) 로 조절 |
| `Works · 05` 표기 | 전체 개수를 자동 계산 |
| "더보기" 버튼 | 작품이 노출 개수(9개)를 넘을 때만 나타난다 |
| 링 캐러셀 | 개수에 맞춰 배치 각도(360 ÷ 개수)를 다시 계산 |
| 상세 화면 | 이전 · 다음 순환 범위 |
| 썸네일 | `image` 가 있으면 이미지, 없으면 `gradient`, 둘 다 없으면 기본 팔레트 |

주소(`href`)를 적지 않은 작품은 "사이트 방문" 버튼이 꺼진 상태로 보입니다.

### 썸네일 만들기

썸네일은 각 사이트의 메인 화면을 캡처한 이미지입니다.
크기를 직접 맞출 필요 없이, 캡처만 넣고 명령 한 줄을 실행하면 됩니다.

1. 해당 사이트를 띄우고 첫 화면이 완전히 나타날 때까지 기다립니다.
   (사진이 흐림에서 또렷해지거나 문구가 떠오르는 연출이 끝난 뒤)
2. 캡처한 이미지를 `thumbnails/source/` 에 넣습니다. 파일 이름이 곧 결과물 이름이 됩니다.
3. 아래를 실행합니다.

```bash
npm run thumbnails
```

4. `public/works/<파일이름>.webp` 가 만들어집니다.
   `works.ts` 의 `image` 에 `/works/<파일이름>.webp` 로 적으면 끝입니다.

**자동으로 맞춰 주는 것** — 결과물은 언제나 카드 규격인 1280×800(16:10) 입니다.
캡처 비율이 제각각이어도 아래 규칙으로 알아서 처리하므로 내용이 잘리지 않습니다.

| 캡처 비율 | 처리 |
| --- | --- |
| 16:10 과 거의 같음 (차이 6% 이내) | 그대로 채움. 남는 몇 px 만 잘림 |
| 16:10 과 다름 | 전체를 넣고 남는 자리를 가장자리에서 뽑은 색으로 메움 |

가장 깔끔한 결과를 원한다면 캡처 자체를 **16:10 화면 비율**로 잡으면 됩니다.
여백 없이 화면 전체가 그대로 들어갑니다.

### 글과 설정 수정

| 고칠 것 | 파일 |
| --- | --- |
| 사이트 이름 · 첫 화면 문구 · 이메일 · 내비게이션 · 그리드 노출 개수 | `lib/data/site.ts` |
| 서비스 항목 | `lib/data/services.ts` |
| 색 · 간격 · 모서리 · 서체 | `styles/base/tokens.css` |
| 특정 화면의 모양 | `styles/` 안의 같은 이름 파일 |
